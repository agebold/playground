Testing Notes

Facilitator sidebar removed

Unlike the source MSK ACCESS demo, these prototypes have no step-navigator sidebar — participants only see the device frame and the in-screen Continue / Back controls, so upcoming step labels (like "Ineligible") aren't visible ahead of time. Each prototype ends at Plan Results with a simple completion screen.
