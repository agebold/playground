# Marketing Positioning & Copy Bank

Distilled from the Clinic team's *Weight Management Positioning Document — Pre-GLP-1s* (Chris + Clinic team, 2026-05-20). This file holds the **brand voice, hero messaging, and program value props** that govern how the Clinic talks about Weight Management.

> ⚠️ **Phasing note.** The source positioning is for the **current, non-GLP-1 state** of the Clinic. The Weight Management App itself is the planned GLP-1 companion product launching Q3 2026 ([[decisions]] 2026-05-04). Treat this file as the **interim brand voice + durable copy bank**: tone, "we're not" stance, and the six user-need framings carry into the GLP-1 era; the "Bold doesn't prescribe medications" language explicitly will not. When the GLP-1 app ships, this file must be revisited — see [[open-questions]].

---

## Audience framing (interim, pre-GLP-1 launch)

Position the Clinic as helpful to **three sub-audiences simultaneously**:
1. People who are **on GLP-1s**
2. People who are **curious about GLP-1s**
3. People who **want to lose weight without a GLP-1**

This is the bridge stance. Post Q3 launch, audience #3 stays but audience #1 and #2 collapse into "Bold patients on a Bold-prescribed GLP-1."

## Why weight is the lead message

Weight Management is the #1 free-response "Chief Complaint" in Clinic onboarding by a wide margin ([[findings]] #21). Energy/fatigue and pain are real but typically **contributing factors to weight gain**, so they belong as secondary messaging that reinforces the weight headline — not as competing leads.

## Program value props (Clinic positioning)

The Clinic Weight Management Program leads with these. They sit **alongside** — not against — the six in-app value props in [[value-props]]. Mapping:

| Clinic program prop | Maps to app value prop |
|---|---|
| Lose weight. Stay strong. | #2 Lose fat, not strength |
| Covered by Medicare (86% pay $0) | #1 GLP-1 (cost/coverage half) + [[principles]] #11 |
| Personalized, practical, doable care plan — held accountable for real change[^accountability] | #6 Provider in the loop — for safety |
| Go beyond the scale | #3 Body composition tracking made easy |
| Exercise at the level that works for you | #4 Older-adult-specific strength and balance plan |
| Practical nutritional support | #5 Convenient diet guidance — not another logging app |
| Support from experts in healthy aging | reinforces #4, #5, #6 |
| Focus on lifestyle (75% of health outside prescriptions) | **pre-GLP-1 only** — see Phasing note below |

[^accountability]: Per the 2026-05-21 LP review, "follow-up appointments + care plan" reads as descriptive table stakes; "held accountable for real change" is the load-bearing benefit. "Provider-created" was rejected as table stakes — use "personalized + practical + doable" instead. See [[findings]] #34–35.

### Standout proof point
> **86% of Bold patients pay $0 out of pocket.** Use early and clearly — pair with any "Covered by Medicare" line. Reinforces [[principles]] #11 (cost is a feature, not a footnote).

### "Focus on lifestyle" — phasing caveat

The source doc says: *"Bold doesn't default to prescribing you another medication, because our specialty is the 75% of your health that happens outside of prescriptions."* This is **load-bearing for the pre-GLP-1 phase only.** Once the Clinic prescribes GLP-1s in Q3, this exact framing has to soften — the new line is closer to *"Bold combines the medication that works with the 75% of your health that happens outside of it."*

## "We're not" — durable boundaries

The Clinic's positioning explicitly rejects these (and so does the app — see [[principles]] #1, #8, #9):

- **Not a calorie counter**
- **Not a meal tracker**
- **Not a fitness tracker**
- **Not a wearable device**
- **Not restriction-based**
- **Not a "mindful-wellness" app** — "mindful" reads as fluffy for what we're offering. *(2026-05-21 LP review; [[findings]] #36.)*
- *Not a place to get GLP-1s* — **pre-GLP-1 only**, drops in Q3.

If an app screen reads like any of these, redo it.

## User-need → copy bank

Six user needs paired with provider-voice copy from the Clinic positioning doc. Use these verbatim or as a starting point for screens, onboarding, lifecycle emails. The user-need labels are themselves valuable — they tell you which job-to-be-done a screen is serving.

| User need (verbatim label) | Where to use in the app |
|---|---|
| *"Help me lose weight without getting weaker"* | Hero, program intro, post-onboarding summary |
| *"Don't make me figure it out from scratch"* | Care plan reveal, daily action screen, "next step" CTAs |
| *"Don't make me log every bite"* | Nutrition module entry, restaurant/menu guidance, pre-meal flow |
| *"Make the exercise feel doable for my body"* | Exercise module entry, routine personalization, seated/balance UX |
| *"Show me progress that means something"* | Progress / body comp screens, milestone celebrations |
| *"Tell me why the clinician matters"* | Provider intro, side-effect check-ins, dose adjustment flows |

> Full provider-voice copy for each need is in [`raw/2026-05-20-weight-management-positioning-pre-glp1.md`](../raw/2026-05-20-weight-management-positioning-pre-glp1.md#weight-management-user-needs--associated-messaging). Pull quotes from there rather than paraphrasing.

## How to apply this file

- **Drafting any user-facing copy?** Start here, not in your head. Choose a hero line from the copy bank or quote the user-need messaging verbatim. Deviate only if the research supports it.
- **Reviewing UI copy?** Run it through the "We're not" list. If it sounds like a calorie counter, meal tracker, fitness tracker, wearable, or restriction-based program → redo it.
- **Designing a new screen?** Identify which of the six user needs it serves, then use the matching provider-voice paragraph as the tone target.
- **Shipping anything that touches GLP-1s?** Stop and re-check this file's phasing note — the "we don't prescribe" language has to be retired, and so does "not a place to get GLP-1s."
